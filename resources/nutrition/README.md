# Локальный справочник КБЖУ

Каталог построен только из официальных CSV-релизов USDA FoodData Central:

- Foundation Foods, выпуск 2026-04-30;
- SR Legacy, финальный выпуск 2018-04.

`catalog.csv` содержит только записи с полным набором kcal, белков, жиров и углеводов на 100 г. Исходные английские описания сохранены. Русские названия и алиасы есть только у явно проверенных записей из `aliases.json`; весь каталог не считается переведённым.

Текущий ограниченный русский слой содержит 40 проверенных записей и 85 алиасов. Он покрывает гречку, рис, яйца, куриную грудку, масла, яблоко, банан, овсянку, картофель, молоко с указанной жирностью, натуральный йогурт, хлеб, говядину, лосось, треску и несколько базовых овощей. Способ приготовления и числовые уточнения сохраняются. Запрос `творог 9%` намеренно не связан с американским cottage cheese другой жирности.

`provenance.json` фиксирует URL архивов, SHA-256, версии, число импортированных и пропущенных записей и идентификаторы нутриентов. Для Foundation energy выбирается в порядке 2048, 2047, 1008; для SR Legacy используется 1008. Белки, жиры и углеводы используют идентификаторы 1003, 1004 и 1005.

Расчёт выполняется локально по формуле `значение на 100 г * масса / 100`. Выбранный продукт всегда подтверждает человек. FDC ID остаётся постоянным идентификатором; позиция в поисковой выдаче им не является.

Сборка на машине с достаточной памятью:

```sh
python3 scripts/build_nutrition_reference.py \
  --foundation-zip /path/to/Foundation.zip \
  --sr-legacy-zip /path/to/SR-Legacy.zip \
  --output-dir resources/nutrition
```

Если пути к архивам не переданы, скрипт потоково загружает закреплённые официальные архивы. Перед импортом SHA-256 обязан совпасть с закреплённым значением.

`norms-plan-template.xlsx` предназначен для импорта плана норм. Заполняется только лист `План`; лист `Пример` содержит учебные числа и не импортируется. Каждая строка действует от указанной даты до даты следующей строки. Парсер не выполняет формулы и полностью отклоняет книгу при любой ошибке.
