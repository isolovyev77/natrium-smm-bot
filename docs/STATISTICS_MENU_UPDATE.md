# Обновление меню статистики

## Цель изменений

Улучшение пользовательского интерфейса настроек бота:
1. Вынести все опции статистики в отдельное подменю
2. Исправить отображение валюты для OpenAI ($ вместо ₽)

## Изменения в структуре меню

### До изменений

```
⚙️ НАСТРОЙКИ БОТА
├── 🤖 Выбрать AI модель
├── 🔄 Переключить статистику
├── 📊 Показать статистику сессии
├── 🔄 Сбросить счетчики сессии

│   ├── 🔄 Переключить статистику

└── ✖️ Закрыть
```

## Реализованные изменения

### 1. Создано подменю статистики (`stats_menu`)

Добавлен новый обработчик `stats_menu` который показывает:
- Текущий статус вывода статистики (Включен/Выключен)
- Кнопку переключения статистики
- Кнопку просмотра статистики сессии
- Кнопку сброса счетчиков
- Кнопку возврата к основным настройкам

### 2. Обновлены callback обработчики

- **`toggle_stats`**: Теперь после переключения показывает подменю статистики (не главное меню настроек)
- **`reset_stats`**: После сброса счетчиков возвращает в подменю статистики
- **`view_stats`**: Исправлен расчет стоимости для OpenAI

### 3. Исправлено отображение валюты

#### В `view_stats` callback:

```python
if provider == 'openai':
    # Примерная цена для OpenAI
    avg_input_price = 0.000003  # усредненная между gpt-4o-mini и gpt-5.2
    avg_output_price = 0.000015
    total_cost_usd = (stats['total_input_tokens'] * avg_input_price) + 
                     (stats['total_output_tokens'] * avg_output_price)
    cost_text = f"~${total_cost_usd:.6f}"
    currency = "$"
else:
    # Расчет для Yandex в рублях
    total_cost = (
        (stats['total_input_tokens'] - stats['total_cached_tokens']) / 1000 * PRICING['input'] +
        stats['total_cached_tokens'] / 1000 * PRICING['cached'] +
        stats['total_output_tokens'] / 1000 * PRICING['output']
    )
    cost_text = f"~{total_cost:.4f} ₽"
    currency = "₽"
```

#### В `format_token_stats` функции:

Функция уже была обновлена ранее для корректного отображения валюты в зависимости от провайдера.

## Навигация

### Пользовательский путь:

1. Пользователь нажимает "⚙️ Настройки"
2. Видит упрощенное меню с кнопкой "📊 Статистика"
3. Нажимает "📊 Статистика"
4. Открывается подменю со всеми опциями статистики
5. После любого действия (переключение, сброс) остается в подменю статистики
6. Кнопка "⬅️ Назад к настройкам" возвращает в главное меню настроек

### Расчет стоимости для OpenAI:

Используются усредненные цены, так как в одной сессии могут использоваться разные модели:
- **gpt-4o-mini**: $0.000003/token (input), $0.000006/token (output)
- **gpt-5.2**: $0.00003/token (input), $0.00015/token (output)
- **Усредненные**: $0.000003 (input), $0.000015 (output)

Это приблизительный расчет, так как точное соотношение использования моделей неизвестно.

## Проверка работы

1. Запустите бота: `bash run.sh`
2. Откройте настройки: `/settings`
3. Проверьте, что в главном меню только:
   - 🤖 Выбрать AI модель
   - 📊 Статистика
   - ✖️ Закрыть
4. Нажмите "📊 Статистика"
5. Проверьте подменю статистики
6. Переключите статистику - должен остаться в подменю
7. Просмотрите статистику сессии - проверьте валюту ($ для OpenAI, ₽ для Yandex)
8. Сбросьте счетчики - должен остаться в подменю
9. Нажмите "⬅️ Назад" - должен вернуться в главное меню настроек
