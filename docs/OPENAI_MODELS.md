# OpenAI Models: Выбор оптимальной стратегии

## 🎯 Рекомендованная конфигурация (2-шаговый пайплайн)

### Шаг 1: Генерация тем (10 идей)
**Модель:** `gpt-4o-mini`

**Почему:**
- ⚡ Быстро (генерация за 1-2 сек)
- 💰 Дешево (~$0.15 за 1M входных токенов)
- 🎨 Достаточное разнообразие для списка тем
- ✅ Отлично справляется с структурированным выводом

**Альтернативы:**
- `gpt-5-nano` / `gpt-5-mini` - еще дешевле (если качество устроит)
- `gpt-4o` - если нужно больше креатива в темах

### Шаг 2: Генерация поста (500-1000 символов)
**Модель:** `gpt-5.2`

**Почему:**
- 📝 Высокое качество текста
- 🧠 Креативность и связность
- 💡 Лучшее понимание контекста
- 🎭 Естественный тон и стиль

**Альтернативы:**
- `gpt-4o` - компромисс качества/скорости/цены
- `gpt-4-turbo` - если gpt-5.2 недоступен

---

## 💰 Стоимость (примерная, февраль 2026)

### gpt-4o-mini
- Input: **$0.15** / 1M токенов
- Output: **$0.60** / 1M токенов
- **Кейс:** Генерация 10 тем (~500 токенов) = **$0.0003**

### gpt-5.2
- Input: **$3.00** / 1M токенов
- Output: **$15.00** / 1M токенов
- **Кейс:** Генерация поста (~2000 токенов) = **$0.03**

### Итого на 1 пост с выбором темы:
**~$0.03** (3 цента)

## ⚙️ Конфигурация в .env

```env
# Рекомендованная конфигурация
OPENAI_THEMES_MODEL=gpt-4o-mini
OPENAI_POST_MODEL=gpt-5.2

# Бюджетная конфигурация (дешевле, но качество ниже)
OPENAI_THEMES_MODEL=gpt-5-mini
OPENAI_POST_MODEL=gpt-4o

# Премиум конфигурация (качество выше, но дороже)
OPENAI_THEMES_MODEL=gpt-4o
OPENAI_POST_MODEL=gpt-5.2
```

## 🔄 Сравнение с Yandex

| Параметр | Yandex (YandexGPT) | OpenAI (gpt-4o-mini + gpt-5.2) |
|----------|-------------------|--------------------------------|
| **Темы** | ~0.5₽ (~$0.005) | ~$0.0003 |
| **Пост** | ~3₽ (~$0.03) | ~$0.03 |
| **Итого** | ~3.5₽ (~$0.035) | ~$0.03 |
| **База знаний** | ✅ File Search | ❌ Только промпт |
| **Web Search** | ✅ Встроенный | ❌ Недоступен |
| **Качество RU** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **Скорость** | Средняя | Быстрая |

**Вывод:** 
- **Yandex** - лучше для фактических данных (благодаря File Search + Web Search)
- **OpenAI** - лучше для креативного текста и скорости

## 📊 Производительность

### gpt-4o-mini (темы)
- Генерация 10 тем: **1-2 сек**
- Размер контекста: 128K токенов
- Температура: 0.7 (баланс креатива)

### gpt-5.2 (посты)
- Генерация поста 500-1000 символов: **3-5 сек**
- Размер контекста: 200K токенов
- Температура: 0.7-0.8 (больше креатива)

## 🛡️ Fallback стратегия

Если модель недоступна, используется такая цепочка:

### Для генерации тем:
1. `gpt-4o-mini` (основная)
2. `gpt-4o` (fallback)
3. Yandex (если OpenAI полностью недоступен)

### Для генерации постов:
1. `gpt-5.2` (основная)
2. `gpt-4o` (fallback)
3. `gpt-4-turbo` (fallback 2)
4. Yandex (если OpenAI полностью недоступен)

## 💡 Рекомендации

✅ **Используйте 2-шаговый пайплайн:**
- Темы: `gpt-4o-mini`
- Посты: `gpt-5.2`

✅ **Запасной вариант:**
- Темы: `gpt-4o-mini`
- Посты: `gpt-4o`

- `gpt-4o` для обоих шагов (золотая середина)

- `gpt-4o-mini` для обоих (максимум экономии)
